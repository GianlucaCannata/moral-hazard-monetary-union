## Description

This repository contains the Python simulation code used to produce 
the numerical results reported in the paper. The code generates:

- Phase portraits across protection regimes (Figure 5.1)
- Bifurcation diagram on adjustment speed (Figure 5.2)
- Bifurcation diagram on implicit protection parameter (Figure 5.3)
- Post-bifurcation phase portraits (Figure 5.4)
- Regime map in the (μ, K₀) plane (Figure 5.5)
- Local stability map in the (α, β) plane (Figure 5.6)
- Historical vs counterfactual dynamics (Figure 5.7)

## Requirements

Python 3.x  
numpy  
matplotlib

## Usage

Run each script independently to reproduce the corresponding figure.
